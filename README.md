# Reform Australia Website (CRCA Website Redesign)

A modern, fast, data-driven website prototype for the **Christian Reformed Churches of Australia (CRCA)** built with **React 19, Vite, Tailwind CSS v4, and TypeScript**.

🌐 **Live Preview (GitHub Pages):** **[https://aussie-app-studio.github.io/Reform-Australia-Website/](https://aussie-app-studio.github.io/Reform-Australia-Website/)**

🧪 **v2 Preview (Safe Church + Sermon Archive + fixes, branch `v2`):** **[https://aussie-app-studio.github.io/Reform-Australia-Website/v2/](https://aussie-app-studio.github.io/Reform-Australia-Website/v2/)**

The original prototype is preserved as the git tag `jesse-v1` and branch `jesse-original`.

## Getting Started (Viewing Locally or Editing with Claude Code)

### Prerequisites
- [Node.js](https://nodejs.org/) (v20 or v22+ recommended)

### 1. Clone & Run Locally
```bash
git clone https://github.com/Aussie-App-Studio/Reform-Australia-Website.git
cd Reform-Australia-Website
npm install
npm run dev
```
Then open the local URL shown in your terminal (typically `http://localhost:5173`) in your browser.

### 2. Using with Claude Code
This repository includes a [`CLAUDE.md`](./CLAUDE.md) guide at the root. Open this folder in **Claude Code** and it will automatically understand the project structure, data files, verification scripts, and build workflow.
